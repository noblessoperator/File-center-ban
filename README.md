🌐 À propos

File Center est une interface web moderne conçue pour centraliser et organiser différents fichiers et ressources dans un espace simple, rapide et accessible.

L'objectif est de proposer un centre de fichiers propre, responsive et facile à utiliser, aussi bien sur mobile que sur ordinateur.

🚀 Installation

1️⃣ Télécharger le projet

git clone https://github.com/USERNAME/file-center.git

2️⃣ Ouvrir le dossier

cd file-center

3️⃣ Lancer le site

Ouvrez simplement :

index.html

dans votre navigateur.

---

⚙️ Configuration

Les liens des fichiers peuvent être configurés dans :

script.js

Exemple :

const FILE_LINK = "https://example.com/file";

Remplacez l'URL par le lien correspondant à votre fichier.
